# Windows 版 Nextcloud + ONLYOFFICE 接入

当前版本把 Nextcloud 作为统一文件层，把 Nextcloud 中安装的 ONLYOFFICE 应用作为
DOCX、XLSX、PPTX 等文件的在线编辑器。OA 原有在线文档和在线表格继续保留，供历史
数据查看；新入口统一为“云文档中心”。

## 配置

1. 使用超级管理员登录 OA，进入“系统设置”。
2. 在“Nextcloud + ONLYOFFICE”区域填写地址、专用服务账号和该账号生成的“应用密码”。
3. 确认 Nextcloud 已安装并启用 ONLYOFFICE 应用，且它已连接到 Document Server。
4. 保存后立即生效。以后迁移 Nextcloud，只需在该页面修改地址。

管理员可以多选“分类/栏目自动分享分组”。系统给分类父目录新增分组分享，栏目目录
继承父目录权限；同步过程不会删除目录、文件或已有分享。取消选择只停止今后的自动
分享，已存在的分享需在 Nextcloud 中手动取消。

“同步文件资料”是独立于任务、公示、备忘附件的同步功能。有关联分类和栏目的文件按
`分类/栏目/文件资料/类型/文件-ID/原文件名` 保存；只有分类的文件按
`分类/文件资料/类型/文件-ID/原文件名` 保存；没有分类的文档、表格、演示、图片、
音频、视频及其他文件按 `未分类文件/类型/文件-ID/原文件名` 保存。每批最多上传
20 个，可重复执行；只新增或更新目标文件，不清理云端冗余内容。
文件资料同步具有独立的多选分享分组配置，可以与分类/栏目目录分享使用不同分组。
取消分组选择不会自动撤销 Nextcloud 中已经存在的分享。
有关联分类的文件通过分类父目录分享，避免不同分类中的同名“文件资料”目录在接收端
显示为“文件资料(2)”等重复入口；无分类文件仅分享“未分类文件”父目录。

重复执行同步时，系统会跳过已成功同步且目标分类、栏目和文件名均未变化的文件。
同一批次会复用目录与分享检查结果；新增文件、失败记录或分类/栏目发生变化的文件仍会
完整上传和补齐分享，不影响原有同步范围。

单个文件最大 50GB。超过 100MB 的文件同步到 Nextcloud 时使用 WebDAV 分块上传 v2，
每块 20MB，失败后可复用同一文件已经上传成功的分块，最终由 Nextcloud 合并；程序
不会把整个大文件一次性读入内存。Nextcloud 服务端需保证用户剩余配额大于目标文件。

数据库中的管理员配置优先于环境变量。`nextcloud_config.bat` 仍可作为首次部署或
应急配置方式，但日常维护建议使用管理页面。

`NEXTCLOUD_ROOT_PATH` 用于限制 OA 搜索范围，例如设置为 `OA` 后，只搜索该账号
`OA/` 目录。自签名证书应先导入 Windows 信任链；仅临时排障时才将
`NEXTCLOUD_VERIFY_SSL` 设为 `0`。

`nextcloud_config.bat` 含凭据，发布脚本会自动排除它；升级时请单独备份。

## 验证

登录 OA 后打开“云文档中心”，输入 Nextcloud 中的文件名。搜索结果点击后进入
Nextcloud；Office 文件会由 Nextcloud 的 ONLYOFFICE 应用打开。工作台顶部搜索也会
同时返回 OA 上传文件和 Nextcloud 文件。
