# Windows 7 更新说明

本更新包包含应用程序、页面、静态资源和维护脚本，不包含 `data/`、`app/static/uploads/`、`python/` 或日志。

1. 将压缩包解压到现有安装目录之外。
2. 在现有安装目录运行 `office_system\upgrade_windows.bat "C:\现有安装路径\office_system"`，这里的脚本路径指向刚解压的更新包。
3. 脚本会停止服务、备份现有数据库、合并应用文件、执行兼容迁移并启动服务。

更新采用合并复制，不会删除或覆盖现有数据库、上传文件、备份、日志与便携 Python。更新前仍建议另存一份完整安装目录。
