{{ icon('user-key') }} 一、登录与角色

浏览器访问 http://127.0.0.1:5000。局域网访问时，使用启动窗口显示的 LAN 地址。

角色默认账号权限说明
超级管理员admin / admin123用户、系统配置、栏目、日志和全部数据管理
普通用户警号 / 123456查看公示、处理任务、维护备忘、上传下载文件
{{ icon('warning') }} 首次部署后建议立即修改默认密码。

{{ icon('dashboard') }} 二、日常功能

工作台

  • 查看待处理任务、最新公示、备忘和快捷入口。
  • 左侧导航支持多标签页，可同时打开多个功能页面。

任务管理

  • 管理员创建任务，指定负责人、部门、优先级和截止日期。
  • 负责人可接收、处理、完成任务或申请交接。
  • 任务交接需管理员审批。

信息公示与备忘

  • 公示采用"分类/栏目/内容"结构，支持置顶、有效期和富文本。
  • 个人备忘仅本人可见，公共备忘可按角色设置可见范围。

{{ icon('memo') }} 三、在线表格

  • 点击左侧"在线表格"进入列表，管理员可新建表格。
  • 编辑页支持自动保存，也可按 Ctrl+S 手动保存。
  • 表格可发布、预览、导出 XLS，并保留版本历史。
  • 可从 WPS/Excel 复制一个单元格区域，在表格中选中起始单元格后直接粘贴，系统会按行列写入。
  • 表格插件已启用中文语言包，菜单和右键操作默认显示中文。

{{ icon('folder') }} 四、文件与附件

  • 支持文档、图片、压缩包、音视频等常见格式。
  • 单文件限制为 50MB。
  • 文件可关联任务、公示或备忘。
  • 上传文件会保留原始文件名和后缀，下载时仍使用原文件名。
  • 在线文档编辑和预览采用 A4 页面视图，支持从 WPS/Word 粘贴文字、表格和常见格式。
  • 在线文档默认下载为 DOC 文件，并尽量让 Word/WPS 按页面/打印视图打开；在线表格默认下载为 XLS 文件。
  • 文件预览页支持将 DOCX、XLSX、CSV、TXT 等文件导入为在线文档或在线表格；老式二进制 DOC/XLS 建议先用 WPS 另存为 DOCX/XLSX。

{{ icon('archive') }} 六、备份与恢复

python\python.exe backup.py backup
python\python.exe backup.py list
python\python.exe backup.py restore --file 备份文件名.db

数据库位于 data/database.db，上传文件位于 data/uploads/。迁移或重装前务必备份。

{{ icon('gen-briefcase') }} 七、Win7 离线部署

  • 目标系统建议为 Windows 7 SP1 64 位。
  • 如底层模块导入失败，右键管理员运行 install_win7_runtime.bat，必要时重启。
  • 生成发布包使用 python\python.exe make_release.py。
  • 生成全新数据包使用 python\python.exe make_release.py --fresh-data。

{{ icon('warning') }} 九、故障排查

  • 无法登录：确认账号密码正确，且账号未被禁用。
  • 服务打不开：运行 status.bat 查看 5000 端口是否监听。
  • 端口占用：运行 stop.bat 后再启动。
  • 运行库错误：运行 diagnose.bat，并查看 FAIL 信息。
  • 后台启动失败：查看 logs/server-error.log。
